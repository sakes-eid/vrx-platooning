## sydney_occupancy.py

### Description

Generate a 2D occupancy grid map from the Sydney Regatta Gazebo terrain model.

The script extracts the shoreline geometry from the `sydney_regatta_shore.dae` file and converts it into a binary occupancy grid for path planning.

---

### Function

Main steps:

1. Find the Sydney Regatta `.dae` terrain file from Gazebo Fuel.
2. Extract terrain vertices and triangles.
3. Project the terrain into the XY plane.
4. Generate a 2D occupancy grid.

Grid configuration:

* Area:

  * X: -700 ~ -300 m
  * Y: 100 ~ 400 m
* Resolution: 2 m/cell

Occupancy value:

* `0`: free water area
* `1`: occupied terrain

---

### Input

Gazebo Sydney Regatta model:

```
~/.gz/fuel/fuel.gazebosim.org/openrobotics/models/sydney_regatta/
```

The script automatically searches for:

```
meshes/sydney_regatta_shore.dae
```

---

### Output

Generated files:

```
data/
└── sydney_local_occupancy.npy

output/
└── sydney_local_occupancy.png
```

The `.npy` file is used by the following planning algorithms.

---

### Run

```bash
python3 sydney_occupancy.py
```

After execution, the script displays the generated occupancy map and saves the results.

## sydney_straight.py

### Description

Generate a straight reference trajectory on the Sydney Regatta occupancy map.

This script creates a set of waypoints between a start point and a goal point. The generated path is used as a reference trajectory for robot trajectory tracking.

---

### Function

Main steps:

1. Load the occupancy grid generated by `sydney_occupancy.py`.
2. Define a start point and a goal point in Gazebo world coordinates.
3. Generate intermediate waypoints along a straight line.
4. Display the trajectory on the occupancy map.
5. Save the generated path.

Path generation parameters:

* Start position: defined in world coordinates `(x, y)`
* Goal position: defined in world coordinates `(x, y)`
* Waypoint spacing: configurable distance between points

---

### Input

Occupancy map:

```text
data/
└── sydney_local_occupancy.npy
```

The occupancy map provides the environment representation and allows the trajectory to be visualized in the Sydney Regatta area.

---

### Output

Generated files:

```text
output/
├── sydney_straight_path.png
│
├── sydney_straight_path.csv
│
└── sydney_straight_path.npy
```

The path files contain the generated reference waypoints:

```text
(x1, y1)
(x2, y2)
...
(xn, yn)
```

---

### Run

```bash
python3 sydney_straight.py
```

The script displays the occupancy map with the straight trajectory and saves the generated path.

## sydney_coverage.py

### Description

Generate a coverage path inside a user-selected area of the Sydney Regatta occupancy map.

The script creates a back-and-forth coverage trajectory over free-water cells and uses A* to connect the path segments while avoiding occupied terrain.

---

### Function

Main steps:

1. Load the occupancy grid generated by `sydney_occupancy.py`.
2. Display the map and let the user select two opposite corners of a rectangular coverage area.
3. Ask the user to define the coverage path width.
4. Generate alternating horizontal coverage lines inside free-water areas.
5. Use A* to connect:

   * the boat start position to the coverage area;
   * consecutive coverage segments;
   * the final point back to the initial boat position.
6. Convert the path from grid coordinates to Gazebo world coordinates.
7. Save and display the final coverage path.

A* uses 8-direction movement and prevents diagonal corner cutting through obstacles.

---

### Input

Occupancy map:

```text
data/
└── sydney_local_occupancy.npy
```

The user must also provide:

* two mouse clicks defining the coverage rectangle;
* the desired coverage path width in meters.

The boat starts from the predefined initial position:

```text
x = -533.7402476486775
y = 161.7656784075805
```

---

### Output

Generated files:

```text
output/
├── sydney_coverage_path.npy
├── sydney_coverage_path.csv
└── sydney_coverage_path.png
```

The CSV file contains:

```text
waypoint_id, x, y
```

The script also prints:

* number of generated waypoints;
* first and last waypoint;
* total path distance.

---

### Run

```bash
python3 sydney_coverage.py
```

After launching the script:

1. Click two opposite corners of the desired coverage area.
2. Enter the desired path width.
3. The final path is generated automatically.
